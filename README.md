# AAA – נעילת מחשב לפי רשימה לבנה

תוכנה ל-Windows שנועלת חשבון משתמש רגיל (לא מנהל) כך שירוצו בו **רק** התוכנות שהוגדרו מראש.
בנויה בשלבים:

| שלב | לשונית | מה עושה |
|---|---|---|
| א+ב | **מדיניות (GPO)** | כל הגדרות ה-GPO והרישום שסוגרות דרכים לבטל חסימה, כמתגים. ביטול מחזיר את הערך המקורי. מיפוי מלא: [docs/GPO-MAP.md](docs/GPO-MAP.md) |
| ג | **ביוס ו-WinRE** | מצב קושחה / Secure Boot, השבתת סביבת השחזור (WinRE + Automatic Repair), רשימת חובה לנעילת הביוס, כפתור הפעלה מחדש לביוס |
| ד | **ניקוי Windows** | סריקה והסרה של Edge, נגני מדיה, Quick Assist, Xbox, Copilot, WSL, Sandbox, Hyper-V, PowerShell 2.0 ועוד |
| ה | **תוכנות מורשות** | פרופילים לוורד, אוצריא, אוצר החכמה, שו"ת בר אילן, מציג PDF, תמונות, סייר – "חפש במחשב" מוצא את כל התיקיות הנחוצות (כולל רכיבים נלווים); הוספה ידנית של תיקייה/קובץ; אזהרה ונעילה לתיקיות שהמשתמש יכול לכתוב אליהן |
| ו | **רשימה לבנה** | ברירת מחדל: הכל חסום. שני מצבים: **מחמיר** (רק תוכנות מאושרות) או **רגיל** (כל Program Files, חוץ מ-Edge/נגני מדיה/IE ומתיקיות שמשתמש רגיל יכול לכתוב אליהן – נסרקות אוטומטית). AppLocker (EXE, MSI, סקריפטים, אפליקציות חנות) במצב בדיקה או אכיפה + שירות Watchdog (SYSTEM) עם מצב למידה + חסימת כלים מסוכנים בתוך Windows |
| – | **יומן חסימות** | מה נחסם / היה נחסם (Watchdog + אירועי AppLocker 8003/8004), עם "התר תיקייה" / "התר קובץ" בלחיצה |

## שימוש

1. להוריד את `AAA.exe` מלשונית **Releases** ולהריץ מחשבון מנהל.
2. **חשבונות יעד** – לבחור את החשבון הרגיל (צריך שיתחבר אליו פעם אחת לפני כן).
3. **מדיניות** – "סמן את המומלצים".
4. **ביוס ו-WinRE** – לנעול ביוס ידנית לפי הרשימה, להשבית WinRE.
5. **ניקוי** – לסרוק ולהסיר.
6. **תוכנות מורשות** – "חפש במחשב" לכל תוכנה ולהוסיף.
7. **רשימה לבנה** – להפעיל AppLocker **במצב בדיקה** ואת הוואצ'דוג **במצב למידה**, "החל שינויים".
8. לעבוד כמה ימים בחשבון היעד בכל התוכנות, לעבור על **יומן החסימות** ולהתיר מה שחסר.
9. לעבור למצב אכיפה (AppLocker) ולבטל מצב למידה (Watchdog), "החל שינויים".

כל השינויים (חוץ מ-WinRE, ניקוי ורשימת הביוס – שמיידיים) נכנסים לתוקף רק ב"החל שינויים".
"ביטול הכל" מחזיר את המחשב למצב המקורי.

## מודל האבטחה

* מיועד לחסום **משתמש רגיל**. מנהל יכול לבטל הכל – לכן לחשבון היעד אסור להיות מנהל, וסיסמת המנהל לא אצלו.
* בלי נעילת ביוס + השבתת WinRE אפשר לעלות מ-USB / סביבת שחזור ולעקוף הכל.
* תיקייה מותרת שהמשתמש יכול לכתוב אליה = פרצה (מעתיק אליה EXE ומריץ). התוכנה מזהה ומציעה "נעל כתיבה".
* תוכנה שמותקנת ב-AppData: היתר לפי נתיב מדויק שם = פרצה (אפשר להחליף את הקובץ). התוכנה מציעה **היתר לפי חתימה דיגיטלית** (מפרסם + מוצר, ב-AppLocker וגם בוואצ'דוג – עם אימות החתימה), או הדרכה להעברה ל-Program Files (התקנה לכל המשתמשים / העתקה / `winget --scope machine`).
* בתוך C:\Windows: התיקיות הפתוחות לכתיבה (Temp, Tasks, Tracing, System32\Tasks, spool\drivers\color ועוד) מוגדרות כ**חריגים** בכלל ההיתר – לא ככללי Deny לקבוצת Users, כי גם המנהל חבר ב-Users.
* העיצוב זהה ל-HGEC (אלף המגן).
* AppLocker: לפי Microsoft (KB5024351) בדיקת המהדורה הוסרה ב-Windows 10 2004+ ו-Windows 11 – עובד גם ב-Pro. ב-Home – לבדוק במצב בדיקה; הוואצ'דוג עובד בכל מקרה.

## בנייה

GitHub Actions בונה בכל push ל-`main` ומפרסם `AAA.exe` בלשונית Releases.
מקומית: Windows + .NET 10 SDK:

```
dotnet publish App/AAA.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o out
```

## קבצים

`C:\ProgramData\AAA\` – `config.json` (הגדרות + גיבוי הערכים המקוריים), `aaa.log`, `blocked.log` (יומן הוואצ'דוג), `applocker.xml`, `AAAWatch.exe` (השירות).

| קובץ קוד | תפקיד |
|---|---|
| `Policies.cs` | קטלוג המדיניות והחלתה עם גיבוי/שחזור |
| `Reg.cs`, `Users.cs` | רישום, טעינת NTUSER.DAT של משתמש לא מחובר, רשימת חשבונות |
| `Recovery.cs` | WinRE, BCD, קושחה, רשימת הביוס |
| `Debloat.cs` | ניקוי Windows |
| `AppProfiles.cs` | פרופילי התוכנות, גילוי תיקיות, בדיקת/נעילת הרשאות כתיבה |
| `Whitelist.cs` | הכללים המשותפים (מה מותר בתוך Windows, כלים חסומים) |
| `AppLocker.cs` | בניית XML, החלה, קריאת אירועים |
| `Watchdog.cs` | שירות הוואצ'דוג |
| `MainWindow.cs`, `Pages*.cs` | הממשק |
